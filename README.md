# Week 04 – Deploying the KoalaTech University Course Registration System

## Overview

In Week 04, you will deploy the **KoalaTech University Course Registration System** using two different deployment approaches.

### Example 1 – Azure App Service

Deploy the application to Microsoft Azure using Azure Container Registry, Azure App Service, and Azure Database for PostgreSQL Flexible Server.

### Example 2 – Local Kubernetes

Deploy the same application to a local Kubernetes cluster using Docker Desktop and Kubernetes.
